# 华农生活指南

华南农业大学「吃 / 住 / 行」一站式校园信息聚合网站。

## 功能
- 关键词搜索框，实时过滤（搜食堂、宿舍、地铁、外卖群等）
- 「吃 / 住 / 行」三板块切换
- 33 条校园生活信息，含位置、描述、标签、来源
- 长描述可展开全文，桌面 + 手机自适应

## 技术栈
纯静态单页：HTML + CSS + 原生 JavaScript（数据内嵌，无需后端 / 接口）

## 运行
直接用浏览器打开 `华农生活指南.html` 即可，双击即用，无需安装任何环境。

## 数据来源
- 华南农业大学总务部（华农全食堂攻略）
- 小红书帖子（宿舍 / 外卖等）
- 华农在读生个人经验

## 版本计划
- V1（当前）：纯静态单页，数据内嵌
- V2：接入 FastAPI 后端 + 数据接口（前后端分离）
- V3：Agent 自动更新（登录小红书爬取）+ RAG 问答
